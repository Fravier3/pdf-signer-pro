# Instrucciones del proyecto

- Lee `ESTADO.md` antes de trabajar. Continúa desde el último avance verificable.
- Trabaja y documenta en español. Conserva los cambios ajenos y la interfaz existente.
- Haz commits por avance funcional con el código y su verificación. Actualiza `ESTADO.md` al empezar, después de cada avance significativo y antes de cerrar. Sube el progreso a la rama de trabajo del repositorio.
- Para cambios web o PWA, consulta [Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance). Verifica controles táctiles, zonas seguras y actualizaciones de la app instalada.
- Conserva el procesamiento local de PDFs, firmas y fotos. Prueba el flujo afectado antes de darlo por verificado.
